# DIVSHOT - 3D Gaussian Splatting Viewer with Multi-language Support

## 支持的语言
- English (en)
- 简体中文 (zh-CN)
- 繁體中文 (zh-TW)
- 日本語 (ja)
- 한국어 (ko)
- Deutsch (de)
- Español (es)
- Français (fr)
- Русский (ru)

## 多语言实现细节
- 使用简单高效的 JSON 配置文件管理翻译
- 轻量级 Language 类 (<50 行代码) 提供全局翻译支持
- 无缝集成到现有项目，使用项目自带的 nlohmann/json
- 术语统一，所有语言版本保持一致的专业术语翻译
